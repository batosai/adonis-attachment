# Variants

Variants are generated from the bytes of an original attachment. A converter has a key and returns the generated bytes, filename, MIME type, and optional folder.

```ts
import type { VariantConverter } from '@jrmc/adonis-attachment'

const thumbnail: VariantConverter = {
  key: 'thumbnail',
  async convert({ body }) {
    const resized = await resizeWithYourImageLibrary(body)

    return {
      body: resized,
      fileName: 'thumbnail.webp',
      mimeType: 'image/webp',
      folder: 'users/42/variants',
    }
  },
}
```

`VariantGenerationService` reads the original and writes each generated file. With Lucid, wrap it with `LucidVariantGenerationService` to create the corresponding variant rows.

```ts
const generator = new VariantGenerationService({
  attachments: attachmentService,
  converters: [thumbnail],
})

const variants = new LucidVariantGenerationService({
  generator,
  attachments: attachmentService,
  store: new LucidAttachmentStore(),
})
```

If persistence of a generated variant fails, its newly written file is deleted. A missing converter raises `UnknownVariantConverterError`.
